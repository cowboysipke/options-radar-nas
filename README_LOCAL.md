# Windows 本地版 V2

本地 V2 的每日主链路是 IBKR Gateway；Massive 只做历史/EOD复核。富途 OpenD 只在“自选与持仓”页面执行一次性自选导入，导入后不再参与日常行情。

## 启动

双击 `启动异常期权助手.cmd`，打开 `http://127.0.0.1:8787/`。首次启动只显示配置页，不会在配置完成前启动Discord、飞书、回测或行情定时任务。

配置完成后，首页提供“立即采集并生成推荐”。四个页面为：今日推荐、信号明细、自选与持仓、系统诊断。

## IBKR前置条件

先启动本机 IB Gateway。默认连接 `127.0.0.1:4001`，代码使用只读模式，不包含下单接口。系统诊断会显示账户连接、期权链、行情类型和权限错误。

期权若返回部分行情权限错误，系统会把它标成观察状态，不生成实时执行限价。

## 富途一次性导入

在“自选与持仓”点击“从富途导入自选”，临时启动富途 OpenD 并登录；导入完成后可关闭 OpenD。后续自选直接在本地页面维护。
