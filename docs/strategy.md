# Alpha夜航社频道语义与执行规则

本文件记录 2026-08-06 从 Discord `使用指南`、`分析师订阅面板`、`异常期权`、四个分析师频道、`盘后日报`、`日内复盘`和 `pa学习资料`梳理出的底层语义。

## 信息层级

1. `异常期权` 是大额或异常订单流，只表达市场里出现了一笔不寻常的下注。
2. 原始订单字段为标的、行权价、Call/Put、到期日、总权利金、平均成交价和 DTE。
3. 分析师输出是对同一订单流的辅助过滤，不是下单指令。
4. 精确异常合约始终保留评价；实际模拟合约根据 DTE、Delta、价差和 OI 再选择。

## 分析师家族

- `PA / price_action`：K线形态和趋势结构；识别 `ii`、`oo`、`two_bar_reversal`、`failed_breakout`、`truncated_pullback`、缺口及多周期趋势。
- `MR / mean_reversion`：判断价格过度偏离后是否具备均值回归交易条件；输出 `trade/no_trade` 与 1–5 置信度。
- `QMR / mean_reversion`：MR 加量化指标过滤；输出交易/观望、偏多/偏空/中性、高/中/低信心。MR 与 QMR 合并为一个分析家族。
- `FPD / flow_divergence`：寻找期权流方向与标的趋势的背离；没有有效背离时，即使期权方向与趋势一致，也常输出观望。

## 字段语义

- `decision`：TRADE、NO_TRADE、WATCH，是第一层准入门。
- `direction`：BULL、BEAR、NEUTRAL、UNKNOWN，与准入门分开。
- `confidence`：1–5映射到0.2–1.0；高/中/低映射到0.8/0.6/0.3。
- `risk_score`、`win_rate` 独立保存，不并入置信度原值。
- PA/FPD 的入场、目标、止损是标的股票价格。模拟期权只在标的触发后按当时盘口入场。
- 分析师卡中的 `Premium` 是订单总权利金，不是单张期权价格。

## 共识约束

- 同一分析师、同一日、同一合约只保留最新一票。
- MR 与 QMR 共享一个家族，避免相关模型重复加权。
- 没有 TRADE 票时最高 D；一个独立家族确认时最高 C；两个以上独立家族同向才有资格进入 A。
- 方向冲突、家族内部冲突或多数 NO_TRADE 会降级并展示双方依据。
- 频道盘后展示的“最高收益”只作观察，绩效权重使用可成交价格、滑点和固定退出规则重新计算。

## 风险字典

指南明确列出五类风险：临近到期归零、流动性、隐含波动率变化、黑天鹅、过度交易。系统分别通过 DTE、价差/OI、IV、事件标记和最大仓位数控制。
