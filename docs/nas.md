# 飞牛 NAS 部署与维护

本文适用于 `linux/amd64` 飞牛 NAS。部署只包含一个 `options-radar` 容器，不需要额外数据库、更新器或行情容器。

## 1. 部署前准备

准备以下内容即可：

### 富途

- 富途 ID、登录邮箱或手机号
- 富途登录密码
- 可以接收登录验证码的手机
- 美股及美股期权行情权限

系统会把登录密码立即转换为 OpenD 协议所需的 MD5 凭据，明文不会写入配置文件。交易密码无需填写。

### DeepSeek

在 DeepSeek 控制台创建一个 API Key。DeepSeek负责分析自由文本和生成易读说明；服务短时异常时，规则解析、评分和日报仍会继续。

### 飞书

创建企业自建应用并开启机器人，复制 App ID 和 App Secret。开启长连接事件接收及机器人消息所需权限。

### Discord

准备能访问目标服务器和下列频道的现有账号：

- 使用指南
- 分析师订阅面板
- 异常期权
- pa分析师
- mr分析师
- qmr分析师
- fpd分析师

实际频道名称不同，可在首次配置页面直接修改。

## 2. 在飞牛中导入 Compose

1. 下载 [`../nas-quickstart/compose.yaml`](../nas-quickstart/compose.yaml)。
2. 打开飞牛 NAS 的 Docker 应用。
3. 进入 Compose 或项目管理，选择新建项目并导入 YAML。
4. 项目名填写 `options-radar`。
5. 启动项目。

Compose只暴露中文面板端口 `8787`。OpenD API `11111` 和维护端口只监听容器内部回环地址，不映射到家庭网络。

首次会拉取镜像，并在容器内部准备固定版本的 Linux OpenD。镜像及 OpenD 文件较大，请等待日志继续滚动，不要连续重复创建项目。

## 3. 获取 SETUP CODE

在飞牛中打开 `options-radar` 容器日志，搜索：

```text
SETUP CODE: xxxxxxxxxxxxxxxxxxxxxxxx
```

浏览器打开：

```text
http://NAS_IP:8787
```

输入 `SETUP CODE` 后进入中文面板。相同口令也保存在持久卷的 `/data/setup-token`。

## 4. 完成首次配置

### 第一步：基础信息和频道

在 `/setup` 检查时区、Discord服务器及七个频道名称。重点确认“使用指南”和“分析师订阅面板”，系统会优先采集这些频道来建立规则库。

### 第二步：富途 OpenD

1. 填写富途 ID、邮箱或手机号。
2. 填写富途登录密码并保存。
3. 点击“发送验证码”。
4. 输入手机验证码；页面显示图形验证码时一并填写。
5. 点击“提交验证码”。
6. 等待状态从“登录中/等待验证码/准备数据”变为 `READY`。
7. 点击“同步富途”，确认能看到持仓和自选。

系统默认保持最高行情权限。若富途手机端或桌面端临时取走行情权，面板会显示权限变化并再次请求保持。最终以 `/system` 中实际行情时间和期权测试结果为准。

### 第三步：自选组

1. 在富途 App 新建自选组 `Options Radar`。
2. 把希望参与筛选的美股加入该组。
3. 返回面板点击“同步富途”。

系统读取全部美股自选组；`Options Radar` 是飞书“添加自选/删除自选”默认操作的组。富途中已有的其他组可以继续保留。

### 第四步：DeepSeek和飞书

1. 填写 DeepSeek API Key。
2. 填写飞书 App ID 和 App Secret。
3. 保存后在 `/system` 检查两项状态。
4. 向机器人发送 `系统状态` 或 `今日推荐` 完成测试。

### 第五步：Discord扫码

1. 等待设置页出现Discord二维码。
2. 使用Discord手机App扫码并确认登录。
3. 保持页面数十秒，等待浏览器会话保存。
4. 点击“立即采集”。
5. 打开 `/rules`，确认能看到使用指南、订阅面板和规则版本。

登录过期时，系统保留采集游标并重新显示二维码；扫码后继续补采。

## 5. 首次验收

依次检查：

1. `/system`：OpenD为 `READY`，Discord、DeepSeek和飞书状态正常。
2. `/portfolio`：富途自选、持仓和快照时间正确。
3. `/rules`：指南、订阅面板、分析师家族和术语已生成。
4. `/contracts`：候选行情包含时间戳及 `native/estimated/missing` 数据质量。
5. 首页：点击“立即采集”和“生成日报”有明确结果。
6. 飞书：收到日报或“当前没有合格推荐”的消息。

没有达到评分和流动性门槛的合约时，日报显示0张候选，这是正常结果。

## 6. 日常操作

日常只需：

- 在富途 App 维护自选；
- 看飞书盘后日报和即时提醒；
- 偶尔打开 `/system` 查看数据时间；
- Discord或富途登录过期时扫码或填写验证码。

飞书常用命令：

```text
今日推荐
查看持仓
添加自选 TSLA
删除自选 TSLA
为什么推荐第1名
重新同步富途
系统状态
```

## 7. 更新与备份

更新前可在 `/system` 点击“创建备份”。然后：

1. 飞牛 Docker 管理器拉取 `stable` 最新镜像。
2. 重新创建 Compose 项目。
3. 等待健康检查通过。
4. 检查 `/system` 和 `/portfolio`。

持久数据位于 `options-radar-data` 卷，包括：

```text
/data/options_radar.db
/data/config.yaml
/data/secrets/
/data/browser-profile/
/data/evidence/
/data/opend-bin/
/data/opend-profile/
/data/strategies/
/data/backups/
```

删除容器或更新镜像时保留该卷。执行“删除项目及其卷”会一并删除数据，应先下载备份。

## 8. 常见状态处理

### 网页打不开

- 确认容器正在运行。
- 确认Compose映射为 `8787:8787`。
- 使用NAS局域网IP，不使用容器内部IP。
- 查看容器健康检查和日志。

### 找不到 SETUP CODE

- 在日志中搜索大写 `SETUP CODE`。
- 确认 `/data` 卷可写。
- 已运行过的容器会继续使用 `/data/setup-token` 中的口令。

### OpenD等待验证

- 在 `/setup` 点击发送验证码并提交手机验证码。
- 出现图形验证码时同时填写。
- 检查富途账号地区、手机号和行情权限。
- 使用“重新登录OpenD”后再试。

### 自选没有更新

- 确认股票属于美股市场。
- 点击“同步富途”。
- 检查 `Options Radar` 组名的空格和大小写。
- 在 `/system` 查看最近一次同步时间和错误信息。

### Discord没有新消息

- 检查 `/rules` 中频道名称。
- 查看设置页是否出现登录二维码。
- 扫码后点击“立即采集”，系统会根据游标补采。

### 中文日报显示异常

- 重新生成日报；新文件使用 UTF-8 BOM。
- 浏览器页面和JSON响应均声明UTF-8。
- Docker镜像包含中文字体和中文OCR资源。

## 9. 交易边界

系统只使用富途的行情、自选和持仓查询能力。交易解锁保持关闭，代码不提供真实下单入口。推荐中的数量、入场、止盈、止损和退出日均属于本地模拟盘参数。
