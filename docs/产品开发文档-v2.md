# 1. 产品定位

以「异常期权 Flow」为入口，以「GEX / Volatility / Market Structure」为交易环境层，服务于**期权卖方优先**的交易决策。

核心定位：

> **本系统卖的是「期权贵不贵 + Gamma 环境允不允许」，不是「方向对不对」。**

本项目与 Nightwatch 的核心差异不变：

> **Nightwatch：Market Structure First**
>
> **本项目：Unusual Flow First**

决策闭环：

```
异常期权 Flow → GEX 判断 Gamma 环境 → Vol 判断期权贵贱 → 价格结构定位
→ 风险过滤（Event / Short Gamma）→ AI 解释（不决策）→ 输出卖方优先方案
```

## 2.2 三条实证结论（v1.0 不知道、但决定产品方向的事实）

90 交易日回测（2026-04-15 ~ 2026-08-18，4935 信号）结论：

1. **方向正确率 ~50%**：四个分析家族全部接近抛硬币（mr 50.6% / fpd 50.7% / pa 48.3% / qmr 48.4%）。→ 方向维度必须降权，不做方向预测。
2. **卖方微利来自权利金溢价**：卖 ATM 期权 +0.66%~0.73%/笔，即使方向随机。→ Vol/流动性维度权重最高。
3. **买方整体负期望**：买原始合约各持有期 -0.5%~-18.3%。→ 产品聚焦卖方 + Defined Risk，买方仅限特定环境。

## 2.3 数据硬限制（必须写入 v2.0）

- **GEX 无法历史回测**：GEX 依赖 OI（T-1 持仓）。富途只提供当前 OI、无历史 OI；Alpaca 历史期权 bars 只有 OHLCV、无 OI。→ GEX 只能**前瞻验证**（上线起记录 GEX，数周后验证 wall/flip 有效性）。
- 富途期权链单次请求跨度 ≤ 30 天，需分批拉取。
- 富途 OI 为 T-1 日度数据，GEX 是"昨天的市场结构"，不做盘中精确择时。

# 5. Module 2：GEX Engine（P0，已调研完毕）

## 5.1 数据流

1. 分批拉期权链（每 ≤30 天一批，富途硬限制）
2. 筛选：DTE ≥ 7（跳过 0DTE/超短期）+ 价内 ±10%（可配置）
3. 批量拉 snapshot（100/批）取 `open_interest` + `gamma`（**富途现成字段，不自算 BS 模型**）
4. 缓存：按 symbol + 交易日缓存，flow 触发时命中直接返回

## 5.2 计算（纯加总，非复杂计算）

```
GEX(strike) = −Σ( OI × lot_size × gamma )
```

负号 = 做市商为反方（标准 SpotGamma 约定）。

## 5.3 输出

- **Net GEX by Strike**：Call GEX / Put GEX / Net GEX
- **Gamma Wall**：|GEX| 最大的行权价（分 Call Wall / Put Wall）
- **Gamma Flip**：净 GEX 从正转负的价格区域
- **Gamma Regime**：Positive / Negative / Mixed（Net GEX 接近 0 时输出 Mixed，不强行二分类）
- 最大正/负 GEX + 当前价格相对 wall 的位置

## 5.4 定位（铁律）

**GEX 是环境层 + 风控层，不进入评分。** 它回答"价格在什么区间有支撑/阻力、做市商偏正还是负 gamma"，不做方向预测。

# 6. Module 3：Volatility Engine（半建成 → 零成本升级）

## 6.1 已完成

- 评分体系已重构为「权利金质量优先」：

| 维度 | 权重 | 依据 |
|---|---|---|
| 权利金质量（IV溢价 VRP + 价差 + OI + 成交量） | 40% | 卖方 alpha 来源 |
| 信号质量（计划完整度+置信度） | 20% | |
| 组合适配（集中度/持仓） | 15% | 风控 |
| 方向共识 | 15% | 降噪（实证 50% 随机） |
| 历史胜率 | 10% | 弱化 |

- IV 溢价 = ATM IV − HV（已实现：HV 自算 20 日年化、ATM IV 单独拉取对齐回测口径）

# 9. Module 6：策略引擎（卖方优先，实证修正版）

## 9.1 策略矩阵（v2.0 修订版）

| 环境 | 优先 | 其次 | 避免 |
|---|---|---|---|
| IV 贵（IV Rank > 70 或 IV/HV > 1.3）+ 正 Gamma | **Sell Put**（或 Bull Put Spread） | Buy Stock | 裸卖 Call |
| IV 贵 + 负 Gamma | **Credit Spread（Defined Risk）** | — | **裸卖**（Short Gamma Risk 层拦截） |
| IV 不贵 + 正 Gamma | 观望（卖方无优势） | — | 买期权 |
| IV 极低 + 事件驱动 + 趋势 | Buy Stock | Bull Call Spread | 裸买 OTM Call（负期望） |
| 方向不明 / Gamma Mixed | 不交易 | — | — |

核心原则：**卖方的唯一强逻辑是「IV 贵 + 环境允许」**；方向只是过滤条件不是决策依据。

## 9.2 Short Gamma Risk 层（P1）

触发条件（AND/OR）：Negative Gamma + 价格接近 Gamma Flip + IV 扩张 + 异常方向 Flow + 短到期。

输出：

```
🔴 Short Gamma Risk: HIGH
Naked Short Call    BLOCK
Naked Short Put     BLOCK
Credit Spread       CAUTION
Defined Risk        PREFERRED
```

## 9.3 Strike / Expiration 推荐（P1）

- Strike：优先选择 Put Wall / Call Wall 外侧一行权价（有 GEX 支撑/阻力参照），同时满足 Delta、价差、OI 过滤
- Expiration：按 IV / Theta / Event Risk / Flow Horizon 选「本周 / 下周 / 2W / 1M」

# 11. Module 8：AI 层（定位铁律，已建成）

**AI 不负责任何数值计算与策略选择**（Gamma/GEX/IV/HV/OI/Greeks 全由程序计算）。

AI 只做：
1. 翻译（Discord 文本整理）
2. 数据审计（复核解析与回测一致性）
3. 解释文案（把程序输出的结论翻译成人话："为什么推荐这个策略"）

不做：Flow 方向解读（P2 再评估）、策略选择、AI 评分。

# 17. 核心闭环（最终形态）

```
发现    异常期权 Flow
  ↓
过滤    是否真有方向意义（分析师共识，弱权重）
  ↓
环境    GEX：Wall / Flip / Regime（正还是负 Gamma）
  ↓
贵贱    IV Rank / IV-HV：期权贵还是便宜
  ↓
位置    价格结构：在 Wall 上方/下方、支撑/阻力
  ↓
风险    Event Risk / Short Gamma Risk
  ↓
决策    卖方优先：Sell Put / Sell Call / Credit Spread / Buy Stock
  ↓
执行    Strike（距 Wall 外侧一格）+ Expiration（本周/下周/2W/1M）
  ↓
验证    历史回测（方向/IV 分层）+ GEX 前瞻验证
```

# 18. 一句话定义

> **Flow-First 的 AI 期权交易决策系统：先发现异常资金，再用 GEX 判断 Gamma 环境、用 Vol 判断期权贵贱，最后针对卖方偏好自动输出「方向 + 环境 + 策略 + Strike + Expiration + 风险」的可执行方案——本系统卖的是"期权贵不贵 + 环境允不允许"，不是"方向对不对"。**
